# Bijoux - Backend e-commerce

## Lancer le projet
1. Ouvrir ce dossier dans VS Code (File > Open Folder)
2. Ouvrir le terminal (Ctrl + ù) puis :
   npm install
3. Verifier le fichier .env (MONGO_URI et SecretOrKey)
4. Creer le compte vendeur (une seule fois) :
   ADMIN_NAME="Khouloud" ADMIN_EMAIL="mail@exemple.com" ADMIN_PASSWORD="motdepasse" npm run create-admin
5. Lancer :
   npm run dev
